📌 Описание задания
Создать веб-приложение для оформления подписки на журнал с интеграцией публичного API Art Institute of Chicago.

Основные требования:
Подключить внешние библиотеки с помощью Composer (Guzzle)
Создать класс для работы с API
Создать класс для сбора информации о пользователе
Реализовать сохранение данных в сессию и cookies
Получать и отображать данные из публичного API
Реализовать кеширование API-ответов (штрафное задание)

⚙️ Как запустить проект
Клонировать репозиторий:

git clone https://github.com/Mishajj39/web/new/lab4
cd web
Установить Composer и зависимости:
Инициализация Composer
composer init
Установка Guzzle
composer require guzzlehttp/guzzle
Запустить веб-серверы: php -S localhost:8000
Открыть в браузере (9 вариант): http://localhost:8000

📂 Содержимое проекта
composer.json  — Конфигурация Composer
composer.lock — Зафиксированные версии зависимостей
vendor/ - Папка с установленными библиотеками
index.php — Главная страница с формой регистрации
save.php — Обработчик формы и API запросов
ApiClient.php — Класс для работы с API
UserInfo.php — Класс для получения информации о пользователе
api_cache.json — Файл кеша API-ответов

✅ Результат
Успешно установлен и настроен Composer с подключением библиотеки Guzzle для HTTP-запросов. Создан класс ApiClient для взаимодействия с публичным API Spaceflight News (новости космонавтики). Создан класс UserInfo для сбора информации о пользователе (IP-адрес, User-Agent, язык браузера, время посещения, идентификатор сессии). Реализована интеграция с API: данные о новостях космонавтики успешно получаются, кешируются в файл api_cache.json и отображаются на странице в виде карточек с заголовком, кратким описанием, датой публикации и ссылкой на полную статью. Реализована работа с cookie (last_submission) для хранения времени последней подписки на журнал и сессиями для сохранения данных формы и API-ответов. Реализовано штрафное задание: кеширование API-ответов с временем жизни 5 минут, кнопка обновления данных через AJAX без перезагрузки страницы с использованием fetch, обработка ошибок API с выводом понятных сообщений пользователю (ошибки подключения, недоступность API, проблемы парсинга JSON). Форма подписки собирает имя, email и частоту рассылки с валидацией на серверной стороне.
