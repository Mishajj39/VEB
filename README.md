📌 Описание задания
Модифицировать HTML-форму из ЛР-2 для отправки данных на сервер методом POST.
Создать PHP-обработчик с валидацией данных.
Реализовать сохранение данных в сессии.
Реализовать сохранение данных в файл.
Создать страницу просмотра всех сохранённых данных.
Добавить валидацию с выводом ошибок.
(Штрафное задание) Реализовать сохранение данных в Cookies.

⚙️ Как запустить проект
Клонировать репозиторий:
git clone https://github.com/Mishajj39/web/tree/lab3
cd web

Запустить контейнеры:
docker-compose up -d --build

Открытие php страницы: http://localhost:8080

Открытие HTML Формы (9 вариант): http://localhost:8080/form.html

📂 Содержимое проекта
docker-compose.yml — описание сервиса Nginx

www/index.php — PHP-страница

www/form.html - HTML-Форма с обработчиком JS

www/process.php — обработчик формы

www/view.php — страница просмотра всех данных

www/data.txt — файл с сохранёнными данными

screenshots/ — все скриншоты
