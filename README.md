📌 Описание задания

Создать веб-приложение для оформления подписки на журнал. Вариант 9: имя, срок подписки, журнал, чекбокс «Электронная версия», радио «Формат оплаты». Данные сохраняются в MySQL, выводятся на отдельной странице.


⚙️ Как запустить проект

Клонировать репозиторий: git clone https://github.com/Mishajj39/web
cd web/lab5

Запустить контейнеры: docker-compose up -d --build

Открыть в браузере (9 вариант):

Сайт:http://localhost:8080

Adminer: http://localhost:8081 (движок: MySQL/MariaDB, сервер: db, логин: lab5_user, пароль: lab5_pass, БД: lab5_db)

📂 Содержимое проекта

docker-compose.yml Dockerfile www/    ├── index.php ├── db.php ├── Subscription.php ├── form.html ├── process.php 

✅ Результат
Освоены навыки контейнеризации PHP-приложения с MySQL, использования PDO для безопасной работы с БД, создания классов-репозиториев, обработки форм, валидации данных, вычисления возраста, фильтрации записей. Получен опыт работы с Docker Compose, настройки связей между сервисами (php-fpm, mysql, adminer).
