🎯 Задача работы

Научиться реализовывать асинхронную обработку данных через очереди сообщений (RabbitMQ) в PHP с использованием Docker.


⚙️ Как запустить проект

1. Клонировать репозиторий

git clone https://github.com/Mishajj39/web

cd web/lab7

2. Запустить контейнеры
   
docker-compose up -d --build

3. Открыть в браузере : Сайт: http://localhost:8080 Панель RabbitMQ: http://localhost:15672 (логин/пароль: guest/guest)

4. Протестировать: заполнить форму на сайте → проверить консоль воркера → проверить файл processed.log


📂 Содержимое проекта


docker-compose.yml
Оркестрация контейнеров: PHP, RabbitMQ, Nginx


Dockerfile
Сборка PHP-контейнера с необходимыми расширениями


nginx.conf
Настройки веб-сервера для обработки PHP-запросов


composer.json
Управление PHP-зависимостями (библиотека для RabbitMQ)


www/index.php
Главная страница со статистикой очередей и логами


www/send.php
Producer - отправляет данные студентов в очередь


www/worker.php
Consumer - фоновый обработчик сообщений из очереди


www/QueueManager.php
Класс для работы с RabbitMQ (подключение, отправка, получение, статистика)

✅ Результат работы

Создано веб-приложение, которое:

Принимает данные о студентах через форму

Отправляет их в очередь RabbitMQ (producer)

Фоновый обработчик (consumer) асинхронно обрабатывает сообщения

При ошибке сообщение перенаправляется в очередь ошибок

На веб-странице отображается статистика очередей


www/db.php (опционально)
Подключение к базе данных

www/Student.php (опционально)
ORM-класс для работы со студентами
