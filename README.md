📌 Описание задания

Научиться конфигурировать веб-сервер Nginx для работы с PHP через PHP-FPM.

Освоить базовые принципы PHP (на примере phpinfo()).

Повторить основы HTML: работа с формами, различными типами полей ввода.

Освоить базовую обработку форм с помощью JavaScript без перезагрузки страницы.


⚙️ Как запустить проект

Клонировать репозиторий:

git clone https://github.com/Mishajj39/web/tree/lab2

cd web

Запустить контейнеры:

docker-compose up -d --build

Открытие php страницы: http://localhost:8080

Открытие HTML Формы (9 вариант): http://localhost:8080/form.html

📂 Содержимое проекта

docker-compose.yml — описание сервиса Nginx

www/index.php — PHP-страница

www/form.html - HTML-Форма 

www/script.js - JavaScript-обработка + штрафное

www/stele.css - CSS-стилизация (для штрафного задания)

screenshots/ — все скриншоты
