📌 Описание задания
Реализовать модульное тестирование PHP-приложения с применением фреймворка PHPUnit (аналог pytest) и библиотеки Guzzle с MockHandler (аналог responses). Протестировать класс оформления подписки на журнал (поля: имя, срок подписки, журнал, чекбокс «Электронная версия», радио «Формат оплаты») с реальной MySQL в Docker и с mock-объектом PDO. Выполнить HTTP-тест с мокированием запроса к API регистрации. Обеспечить изоляцию тестовой среды через файл .env.test.

⚙️ Как запустить проект

1. Клонировать репозиторий:
   
git clone https://github.com/Mishajj39/web
cd web/lab8

2. Установить зависимости через Composer:

composer install

3. Запустить Docker-контейнеры:

docker-compose up -d --build

4. Запустить тесты:

vendor\bin\phpunit

🎯 Результат
В ходе выполнения лабораторной работы освоены принципы написания модульных тестов на PHP с применением PHPUnit. Реализованы unit-тесты для класса, работающего с базой данных, тест с mock-объектом для изоляции внешней зависимости (PDO), а также HTTP-тест с полным перехватом запроса через библиотеку Guzzle (MockHandler). Настроено тестовое окружение через .env.test и phpunit.xml, обеспечена переносимость и изоляция тестов с использованием Docker (nginx, php-fpm, mysql, adminer). Полученные знания применимы для построения надёжных и легко тестируемых PHP-приложений.
